# ⚡ JavaScript Operators Practice

This folder contains my daily practice exercises focused on mastering **JavaScript Operators**.

---

## 📋 Exercises Overview

Here is a summary of the 10 core operator challenges completed in `Exercise_Operators_1.js`:

1. **Addition (`+`):** Adding two numbers and storing the sum.
2. **Subtraction (`-`):** Subtracting numbers to find the difference.
3. **Multiplication (`*`):** Multiplying values (calculating total items).
4. **Division (`/`):** Dividing numbers equally across groups.
5. **Remainder / Modulo (`%`):** Finding the leftover remainder after division.
6. **Exponentiation (`**`):** Raising a base number to a power.
7. **Increment (`++`):** Increasing a count variable by 1.
8. **Shortcut Addition (`+=`):** Updating a variable in place.
9. **String Concatenation (`+`):** Joining text strings with spaces.
10. **Data Type Check (`typeof`):** Inspecting strings, numbers, and booleans
